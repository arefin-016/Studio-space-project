


# 🎬 StudioSpace – Creative Workspace & Production Studio Sharing Platform

StudioSpace is a peer-to-peer creative workspace and production studio sharing platform where creative professionals can discover, book, and manage professional creative spaces. Studio owners can list their studios, manage booking requests, and connect with creators looking for suitable workspaces.

---

## 📌 Project Overview

StudioSpace makes it easier for photographers, filmmakers, musicians, podcasters, and other creative professionals to find and book suitable production spaces.

Users can explore different studio categories, view studio details, submit booking requests, and manage their reservations.

Studio owners can create studio listings, update studio information, and manage booking requests by accepting or rejecting reservations.

## ✨ Key Features

### 🔐 Authentication

- Email and password authentication.
- Google and GitHub social login.
- Private routes for authenticated users.
- Secure session management using Better Auth.

### 🏢 Studio Management

- Browse all available studios.
- Explore studios by category.
- View detailed studio information.
- Create new studio listings.
- Edit existing studio listings.
- Delete personal studio listings.
- Dynamic Featured Studios section.
- Display studio ratings, locations, categories, and hourly rates.

### 📅 Booking Management

- Book studios with selected dates and time slots.
- Booking requests are initially saved with Pending status.
- View personal booking history.
- Cancel pending bookings.
- Studio owners can view booking requests.
- Accept or reject booking requests.
- Prevent double bookings by checking time overlaps against existing Confirmed bookings.
- Display clear error messages when booking conflicts occur.

### 🎨 User Interface

- Fully responsive design.
- Light and dark theme support.
- Interactive hero image slider.
- Dynamic studio category cards.
- Modern studio listing cards.
- Toast notifications for user feedback.
- User-friendly navigation.
